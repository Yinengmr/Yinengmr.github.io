docker 好货

docker 换国内源

"registry-mirrors": [
    "https://mirror.baidubce.com/",
    "https://docker.mirrors.ustc.edu.cn",
    "http://hub-mirror.c.163.com"
],

保存镜像

docker save -o wiznote.tar wiznote/wizserver

导入镜像

docker load -i wiznote.tar

安装 portainer面板

创建目录 D:/docker/portainer_data

docker run -d -p 8000:8000 -p 9000:9000 --name=portainer --restart=always -v /var/run/docker.sock:/var/run/docker.sock -v D:/docker/portainer_data:/data portainer/portainer-ce:latest

docker 安装为知笔记

创建目录 D:/docker/wizdata

docker run --name wiz --restart=always -it -d -v  D:/docker/wizdata:/wiz/storage -p 8200:80 -p 9269:9269/udp wiznote/wizserver
