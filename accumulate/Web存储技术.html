Web存储技术

Web存储技术是一组用于在客户端（用户浏览器）存储数据的技术。这些技术使得网页能够在用户本地存储和检索数据，以提高性能、用户体验和在离线情况下继续工作。以下是两种主要的Web存储技术：

localStorage 和 sessionStorage:

  • localStorage： 允许网页在用户的浏览器中存储键值对数据，该数据可以在浏览器关闭后保留。

// 存储数据:
localStorage.setItem('key', 'value');

// 检索数据:
var value = localStorage.getItem('key');

// 移除数据
localStorage.removeItem('key');
// 清空所有数据:
localStorage.clear();
  • sessionStorage： 与localStorage相似，但是数据仅在当前会话期间有效，即当用户关闭浏览器标签或窗口时，数据将被清除。
sessionStorage.setItem('key', 'value');
var value = sessionStorage.getItem('key');

IndexedDB:

IndexedDB 是一个强大的客户端数据库，允许网页异步存储和检索大量结构化数据。与localStorage和sessionStorage不同，IndexedDB是一个事务性数据库系统，可以处理更复杂的数据操作。

// 打开或创建数据库
var request = indexedDB.open('myDatabase', 1);

// 处理数据库打开/创建成功的回调
request.onsuccess = function(event) {
  var db = event.target.result;
  // 进行数据库操作
};
