windows terminal 配置启动命令

在启动配置setings.json文件 profiles.list[]添加以下内容： -Path 指定目录 执行 ./alist.exe start

{
    "commandline": "powershell.exe -NoExit -Command Set-Location -Path D:\\winapp\\Alist ; ./alist.exe start",
    "guid": "{61c54bbd-c2c6-5271-96b7-019a87ff40bf}",
    "hidden": false,
    "name": "start alist"
},

INFO[2024-01-13 20:14:43] success start pid: 24200
PS D:\winapp\Alist>
