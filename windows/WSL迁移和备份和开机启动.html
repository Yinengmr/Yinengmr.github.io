WSL迁移和备份

查看WSL版本和状态

wsl -l -v

开启WSL

wsl -d Ubuntu-18.04

关闭WSL

wsl -d Ubuntu-18.04

关闭所有WSL

wsl --shutdown

导入WSL

使用 wsl --import 命令导出所选发行版的备份。

wsl --import (发行版) (安装位置) (文件路径以及文件名称) --version ( 版本 1 | 2 )

将Ubuntu20.04 导入到 c盘指定文件夹内 wsl --import Ubuntu20.04 c:\WSL d:\WSL\Ubuntu-20.04.tar --version 2

导出WSL

使用 wsl --export 命令导出所选发行版的备份。

wsl --export (发行版) (保存路径以及 文件名称.tar)

将Ubuntu20.04 保存为 Ubuntu20.04.tar，导出到当前目录可以这样写

wsl --export Ubuntu20.04 Ubuntu20.04.tar 将发行版为 Ubuntu20.04 的 Ubuntu20.04 备份文件 保存在d盘指定文件夹内

wsl --export Ubuntu20.04 d:\WSLx\Ubuntu20.04.tar

WSL 开机启动

按住 windows + R 键 输入 shell:startup 打开

出来创建一个 .vbs 文件，然后把下面的代码复制进去

Set ws = CreateObject("Wscript.Shell")
ws.run "wsl -d Ubuntu20.04 -u root /etc/init.wsl start", 0
