WSA 安装前的准备

CPU 启用虚拟化，按照你主板的厂商设置；

进入BIOS选择——高级模式——advanced_cpu configuration——intel virtualization technology——enabled开启，F10保存退出即可解决;

打开 控制面板 -> 程序和功能 -> 启用或关闭 Windows 功能 -> 勾选

  • Hyper-V
  • 适用于 Linux 的 Windows 子系统
  • 虚拟机平台

重启电脑

下载 WSA 安装包

打开安装包抓包网址:https://store.rg-adguard.net

将WindowsSubsystemForAndroid微软商店链接 粘贴进搜索框，右边要选择Slow通道，共有四个选项，分别是Fast，Slow，RP和Retail，分别对应Windows的Dev渠道，Beta渠道，RP渠道和正式版，目前只有Beta版本有发布。

下载最下面的 .Msixbundle 1.4G左右的文件

WSL 安装

管理员模式打开 PowerShell 执行下列命令

Add-AppxPackage -Path D:\downloads\WSA.Msixbundle

安装apk

打开适用于 Linux 的 Windows 子系统 -> 高级设置 -> 开发人员模式 -> 勾选开
