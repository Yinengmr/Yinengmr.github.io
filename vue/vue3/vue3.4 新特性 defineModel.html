    • vue3.4 新特性 defineModel

vue3.4+版本为了让vue更加容易上手，把子组件更新父组件的v-model值逻辑做了升级处理，简化了父组件和子组件双向通信（v-model）的代码，使得双向绑定的逻辑更加明了，这就是defineModel诞生的意义。

没有defineModel之前的代码

子组件

<template>
    <div>
        <input
            :value="modelValue"
            @input="emit('update:modelValue',$event.target.value)"
        />
    </div>
</template>
<script setup lang="js">

// 以前的写法
defineProps(['modelValue'])
const emit = defineEmits(['update:modelValue'])
</script>

或者子组件2

<template>
    <div>
        <input v-model="modelValue" />
    </div>
</template>
<script setup lang="js">

const props = defineProps({
    modelValue: {
        type: String,
        default: ''
    }
})
const emit = defineEmits(['update:modelValue'])

const modelValue = computed({
    get() {
        return props.modelValue
    },
    set(val) {
        emit('update:modelValue', val)
    }
})
</script>

父组件

<template>
    <div>
        <h1>defineModel</h1> 
        <DefineModel v-model.trim="groupName"></DefineModel>
    </div>
</template>
<script setup lang="js">
import DefineModel from './component/DefineModel.vue';
const groupName = ref('')
</script>

但是当遇到props是一个对象的时候代码写的就比较难受了

有了defineModel之后的代码

子组件

<template>
    <div>
        <input type="text" v-model="modelValue" placeholder="请输入内容" />
    </div>
</template>
<script setup lang="js">

const modelValue = defineModel({type: String, default: () => '' })

</script>
